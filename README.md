# Strategy evolution on networks  under payoff uncertainty and risk preference

DESCRIPTION
-----------

This is a Matlab program designed for calculating the benefit-to-cost ratio of any networks under payoff uncertainty and risk preference. 

FILE
-----

Crucial functions:

--f_cal_remeet_time_two: function to calculate two-dimensional coalescence time for any network.

--f_cal_remeet_time_three: function to calculate three-dimensional coalescence time for any network.

--f_cal_remeet_time_four: function to calculate four-dimensional coalescence time for any network.

--f_get_bcratio_average: function to calculate the critical benefit-to-cost ratio of any networks under payoff uncertainty and risk preference.

An important example is provided to show the calculation of the critical benefit-to-cost ratio of a given complete graph:

--Main_well_mixed.m: calculate the critical benefit-to-cost ratio of a given complete graph.
